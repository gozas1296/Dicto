## 功能

| 功能 | 说明 |
| --- | --- |
| **查词** | 查询单词中文、音标、释义与例句 |
| **翻译** | 单词与句子中英双向翻译 |
| **每日一词** | 每日一个单词帮助认识更多单词 |
| **每日短文精读** | 每日一篇短文帮助提升阅读 |
| **日历** | 这一天的名句与历史上的今天 |
| **新闻** | 整合今日英文新闻以便阅读 |
| **设置系统** | 性能设置与个性化选项 |
| **Android体验** | 专注于Android手机使用 |

## 下载

前往 **[GitHub Releases](../../releases)** 页面获取最新版本。

1. 打开 Releases 页面，下载最新版本的安装程序。
2. 在Android手机打开apk安装包安装（最低支持Android7.0）。
3. 启动 Dicto，开始使用。
